# News_app
This is a News_app.
NewsApp is a simple and responsive web application that lets users stay updated with the latest news across different categories. It features a clean UI, search functionality, and category-based browsing.

✨ Features

🔍 Search News – Quickly find articles by keywords.

📂 Categories – Browse news by Tech, Food, Movies, Business, and IPL 2023.

📱 Responsive Design – Optimized for both desktop and mobile.

⚡ Dynamic Content – Fetches and displays the latest articles seamlessly.

🛠️ Built With

HTML5, CSS3, JavaScript

Font Awesome for icons

Google Fonts (Poppins) for typography
